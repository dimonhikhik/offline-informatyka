# Панель учителя

Відкрий **«Панель учителя»** на комп’ютері, де запущено сервер, або перейди до `http://localhost:4173/#admin`. Учнівські пристрої отримують доступ до опублікованих завдань через локальну мережу.

## Додавання роботи

1. Натисни **«Додати практичну»**, введи назву й вибери клас і програму.
2. У розділі **«Інструкція»** запиши завдання для самостійного виконання. Пункти можна переставляти.
3. У розділі **«Матеріали»** додай зображення або файли. Межа для одного файла становить 5 МБ, для однієї роботи — 10 файлів. Зображення показуються в інструкції, а вкладення можна завантажити.
4. У розділі **«Публікація»** переглянь інструкцію й натисни **«Опублікувати»** або збережи роботу прихованою.

Учні побачать зміни після оновлення сторінки. У редакторі ПК кнопка **«Інструкція»** відкриває бічну панель, на телефоні — вікно для читання.

У меню біля картки можна створити копію, керувати видимістю або видалити додану роботу. Для зміненої вбудованої роботи можна повернути стандартний варіант.

## Копії

Меню **«Копії»** дає змогу завантажити практичні роботи з матеріалами й відновити їх із JSON. Перед відновленням панель запитує підтвердження заміни. Сервер зберігає матеріали у `public/site-content.json`, а попередню версію — у `local-server/site-content.backup.json`. Межа для всього пакета матеріалів становить 24 МБ у JSON.

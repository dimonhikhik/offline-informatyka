# QR-код для учнів

1. Зупиніть попередній сервер клавішами Ctrl+C у його вікні.
2. Запустіть `start-lan.bat`. На Windows автоматично відкриється `http://localhost:4173/#connect`.
3. Оберіть адресу Wi-Fi або Ethernet, доступного учням, якщо комп’ютер має кілька мережевих адаптерів. Покажіть код на екрані. Повторне відкриття — кнопка «QR для учнів» угорі сайту.
4. Учні підключаються до тієї самої локальної мережі та сканують код камерою. Посилання веде в каталог.

`start.bat` залишає доступ лише на цьому комп’ютері: сторінка пояснює, як перейти до режиму класу, і не створює непридатного для телефонів коду localhost. Сервер не змінює брандмауер. Потрібен дозвіл Node.js для приватної мережі; гостьові мережі можуть ізолювати пристрої.

Код генерується локально бібліотекою Project Nayuki (MIT), доступне завантаження SVG. Інтернет не потрібен. Після зміни IP/мережі натисніть «Оновити адреси» й за потреби заново завантажте код. Дані учнів зберігаються в їхніх браузерах за адресою сайту, а не на сервері вчителя.

Ручні сценарії: відкриття після start-lan.bat; сканування телефоном зі спільної мережі; вибір іншого адаптера; завантаження SVG; звичайний start.bat показує пояснення; вимкнена мережа показує повідомлення без QR. Тести, збірка, лінтинг і браузерні перевірки не запускалися відповідно до інструкцій проєкту.
